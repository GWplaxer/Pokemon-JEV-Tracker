EV Value by Packaging

Sets ranked by overall value per dollar. The best format for each set is highlighted.

What each column means

Rank
Where the set places once every set is sorted from best to worst.
EV / pack
Expected value: the average amount of card value we estimate you get from opening one pack of the set.
Avg cost / pack
What a single pack typically costs you once it’s bought as a mini tin, ETB or booster box.
Set score
The set’s overall value for money. Higher means the cards inside tend to be worth more compared with what the packs cost.
Format columns
How much card value you get back for every $100 you spend on that product. Higher is better, and the highlighted one is that set’s best format.
Price under each number
The product’s price and where it comes from: “TCGplayer” with a date for real market prices, or “est.” for a placeholder.

Prices tagged TCGplayer are TCGplayer Market Prices (the price TCGplayer calculates from recent completed sales) as published in the Pallet.Club Sealed Product Index, which sources them from TCGplayer via TCGCSV. If the live feed cannot load in your browser, the page shows a saved copy that only has booster boxes. Tagged est. are unchecked placeholders, shown only when the box at the top is unticked.
